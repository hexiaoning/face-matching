# Face Matching

视频人脸比对项目。

## 功能

- 预先录入一批人员照片。
- 照片可以关联 ID、姓名等信息。
- 支持输入视频或接入视频源。
- 将视频中出现的人脸与预录照片进行比对。
- 匹配到预录人员时可以触发报警。

## 支持环境

项目必须支持以下设备和系统：

| 项目 | 配置 |
| --- | --- |
| 设备 | 华硕 ROG G22CH 台式机 |
| CPU | Intel i7-14700KF |
| 显卡 | RTX 4070 SUPER 12GB |
| 内存 | 64GB |
| 系统 | Windows 11 64 位 |

目标设备没有安装 CUDA。

项目应支持一键安装或直接运行。
