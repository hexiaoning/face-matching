离线图像与人车分析 v2.7.0

使用方法
1. 将 ZIP 完整解压到本地文件夹，不要只复制 EXE。
2. 双击“启动离线分析.cmd”或 VideoAnalysis.exe。
3. “人车检测”中打开本地视频并点击“开始检测”：人为红框，车辆为黄框，框左上角显示类别和置信分值。支持暂停、继续、停止、保存当前帧和导出完整标注视频。导出视频无音轨。
4. “图像增强”中打开本地图片，选择参数并应用；可并排查看原图、框选局部、另存 PNG 或导出含原图和参数的 ZIP。纹理抑制也会柔化真实细节，无法恢复缺失信息。

运行条件
Windows 11 x64。图像增强无需 GPU；人车检测需要兼容的 NVIDIA 或 Intel GPU 及对应驱动。包中包含 Python、Qt、OpenCV、CUDA/cuDNN、OpenVINO 和 RT-DETRv2-R50 模型，无需另装 Python、CUDA Toolkit 或联网下载。显卡驱动由目标机预先安装。

模型与性能
采用 RT-DETRv2-R50，默认置信度门槛 0.50，不按尺寸过滤小目标。分值表示目标类别的检测置信度，不表示身份相似度。精度优先，分析速度由目标机 GPU 决定，不保证实时 30 FPS。拍屏样例的误检与漏检表现不能代替原始现场视频验收。

离线自检
命令行运行 VideoAnalysis.exe --check-runtime --report runtime-check.json，可检查运行库与模型哈希。
运行 VideoAnalysis.exe --diagnose --report gpu-check.json，可额外执行真实 GPU 推理。自检可能需要等待 GPU 初始化。
若检测失败，可将报告和完整错误文字交给维护人员。诊断报告不包含图片、视频或个人资料。

发布与更新
仅提供包含应用、运行库和模型的完整 ZIP，无需安装程序。新版本解压到新目录；图片、视频和导出结果由用户选择存放位置，不保存在程序目录中。保留旧版本目录即可回退。
包内 SHA256SUMS.txt 校验每个文件；ZIP 旁的 .sha256 文件校验整个压缩包。请保留随包许可证和第三方说明。
