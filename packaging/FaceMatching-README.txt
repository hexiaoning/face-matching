Face Matching 离线综合分析 v2.8.0

解压完整 ZIP 后，双击“启动综合分析.cmd”。所有功能都在同一个窗口中：
人脸检索、人车检测、图像增强、以图搜索、人员库、标注库、设置。
无需安装 Python、运行库或联网下载模型；神经网络推理需要兼容的 NVIDIA / Intel GPU 驱动。

1. 图像增强
打开原图，选择“人脸清晰化（保守）”或“车牌清晰化（保守）”。
如只处理局部，在原图拖动框选并勾选“仅处理框选的人脸 / 车牌”，应用参数。
框外像素保持原样；处理图尺寸不变，不生成或补画人脸细节、车牌字符。
原图原始文件始终保留；可导出 PNG 或含原图、参数、选区、校验值的 ZIP。
降噪与锐化只能改善可见性，无法保证恢复已缺失的信息。不进行车牌文字识别。

2. 以图搜索
打开目标图片并框选人或物体，添加待搜索的图片、视频或文件夹（含子文件夹）。
人物身份使用“搜索同一人脸（GPU）”；不需要先将该人录入人像库。
物体或人物衣着使用外观模式，查找相同或近似外观；适合纹理清晰、视角接近的目标，
不支持文字描述搜索，不保证跨角度、遮挡、换装的匹配。所有结果均为待人工核实候选。
视频默认每帧搜索；提高抽帧间隔可提速，但可能漏过短暂目标。最多保留500条高分结果。
结果提供来源、帧号、时间、位置和分值；可导出JSON记录或将选中结果送入图像增强。

3. 分类人像库与筛选
在“人员库”点“管理人像库”，建立xx库、yy库等；录入或“设置所属库”可多选分类。
旧人员自动进入默认库。删除分类不会删除人员或照片；无其它归属时移入默认库。
“人脸检索”与“人员库”均支持选择库、性别、省市区县、年龄范围，然后应用筛选。
检索选择来源时会使用当前筛选条件；运行中的批次须先停止再更换筛选。
性别、出生日期和地区按通过校验的18位身份证解析，年龄按中国时区计算周岁。
身份证地址码不代表当前户籍；省市区县名称参考2023年数据，历史地区码可直接输入。
证号无效或不受支持的人员保留原数据，启用身份证条件时不参与筛选结果。

4. 原有功能
图片/视频批量人脸比对、摄像头、RTSP/RTMP、人脸标注纠错、人员照片管理、
标注样本对照与ZIP导出、人车检测与完整标注视频导出均保留。

人脸模型在首次检索或录入时加载；加载失败不会关闭整个程序，可修复后重试。
--image-tools、--video-detection及旧video-analysis命令均打开完整应用并切换到对应页面。
数据沿用 %LOCALAPPDATA%\FaceMatching，可用FACE_MATCHING_HOME指定其它目录。
运行库和全部模型自检：FaceMatching.exe --check-runtime --report runtime.json
加入真实GPU推理自检：FaceMatching.exe --check-runtime --diagnose --report diagnostics.json
仅发布完整离线ZIP，不提供增量包或EXE安装程序。
